SESIÓN
EDITORIAL

Estudio para sesiones fotográficas editoriales en Maracaibo: ciclograma blanco infinito, 7 fondos de papel, iluminación profesional y comodidades para producciones largas de moda, lookbooks y campañas.

El espacio para tu sesión editorial

The Studio 4 está diseñado pensando en producciones editoriales que requieren múltiples cambios de fondo, iluminación versátil y comodidades para que modelos y equipo creativo trabajen cómodos durante jornadas largas. El estudio tiene ambiente con luz controlada (telas blackout), permitiendo crear desde luz natural simulada hasta atmósferas dramáticas con flashes Godox y paneles RGB.

Fondos disponibles

  • Ciclograma blanco infinito de concreto (clásico, sin bordes)
  • 7 fondos de papel: Blanco Ártico, Negro, Gris, Tropical Breeze, Aguajón, Brown Rice, Lemonade, Rojo
  • 3 fondos de tela: Blanco, Negro, Verde
  • Posibilidad de cambiar entre múltiples fondos durante la misma sesión

Iluminación profesional

  • Octagonal softbox Neewer 120cm (luz suave, halo natural)
  • Flashes Godox 300ws — congelan movimiento, perfectos para moda
  • Paneles RGB de color para fondos y efectos
  • Difusores 360° para retratos sin sombras duras
  • Máquina de humo y luces láser para atmósferas dramáticas
  • Spot light direccional

Comodidades para producciones largas

Las sesiones editoriales suelen durar 4-8 horas. El estudio incluye rack de ropa y plancha a vapor para preparación de wardrobe, sistema de sonido bluetooth para ambiente musical, pantalla TV 55" para revisar tomas en vivo, ventilador soplador para hair flow, máquina de hielo, air fryer y caminadora — todo lo que tu equipo necesita para trabajar cómodamente.

Tarifas para sesión editorial

  • Por hora (L-V día): $45 — para sesiones cortas de retrato
  • Media jornada 4h (L-V día): $160 — ideal para lookbook con 1 modelo y 2-3 looks
  • Día completo 8h (L-V): $300 — para editoriales con múltiples modelos, fondos y looks
  • Cámara Lumix G95 + lente 12-60mm: $20/hora si no traes la tuya

Tipos de sesiones editoriales que se realizan

Lookbooks de marcas de moda, campañas estacionales, sesiones de modelaje para books profesionales, branding personal para emprendedores y creadores de contenido, retratos editoriales para revistas, sesiones fotográficas para artistas musicales y portadas de álbum, fotografía de actores para portfolios.
