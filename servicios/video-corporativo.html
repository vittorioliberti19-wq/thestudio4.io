VIDEO
CORPORATIVO

Set de grabación profesional en Maracaibo para video corporativo, institucional, podcast, entrevistas y reels de marca. Ciclograma blanco, chroma key verde y sonido bluetooth para producciones limpias.

¿Por qué grabar tu video en The Studio 4?

The Studio 4 es uno de los espacios mejor equipados de Maracaibo para producción audiovisual. Tenemos ambiente con luz controlada (telas blackout en ventanal), ciclograma blanco infinito, fondos de tela verde chroma para post-producción, sistema de sonido bluetooth para playback y una pantalla TV 55" que funciona como teleprompter o monitor de referencia en vivo.

Equipos incluidos para video

  • Ciclograma blanco infinito de concreto (set principal)
  • Fondo de tela verde para chroma key
  • Octagonal softbox Neewer 120cm
  • Paneles RGB y máquina de humo
  • Spot light + difusores 360
  • Pantalla TV 55" para preview / teleprompter / monitor cliente
  • Sistema de sonido bluetooth para playback
  • Trípode SmallRig 71" + monopie
  • Paral jirafa 3.3m para boom

Tipos de proyectos audiovisuales

Producciones que se han realizado regularmente en el estudio incluyen: videos institucionales corporativos, entrevistas de podcast, contenido para redes sociales (reels, TikTok, YouTube Shorts), tutoriales y cursos online, lookbooks audiovisuales de moda, videoclips musicales, contenido para influencers y creadores, video performance / coreografías y campañas comerciales para marcas.

Equipo adicional en alquiler

  • Cámara Panasonic Lumix G95 + lente 12-60mm: $20/hora — graba hasta 4K
  • Micrófonos Holyland Lark Man 2 (set inalámbrico de 2): $10/hora — calidad profesional para entrevistas

Tarifas para producción de video

  • Por hora (L-V día): $45
  • Media jornada 4h (L-V día): $160
  • Día completo 8h (L-V): $300 — recomendado para producciones largas
  • Sáb/Dom día completo: $380

Para shoots nocturnos hay un cargo de $10 por transporte de personal. Si la producción dura más de 8 horas, hora extra $45.
